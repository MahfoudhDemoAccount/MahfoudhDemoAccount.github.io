## ✨ Features

- **⚡ Lightweight & Fast**: Pure vanilla HTML5 and CSS3 — zero dependencies, zero build steps, and no bloated third-party libraries.
- **📱 Responsive Design**: Seamless layout adapted for all screen sizes from mobile (360px+) to desktop.
- **♿ Accessible (a11y)**: Built with semantic HTML landmarks, ARIA attributes, and accessible keyboard focus indicators complying with WCAG guidelines.
- **🎨 Modern Visual Design**: Custom dark-theme aesthetics with deep navy surfaces (`#0B132B`, `#1C2541`), luminous cyan accents (`#00D2D3`), and fluid typography.
- **🍔 Accessible Mobile Navigation**: Smooth, accessible toggle navigation drawer for smaller viewports.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Typography**: System UI font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`)
- **Icons**: Inline SVG vector graphics
- **Hosting**: GitHub Pages

## 🚀 Local Development

To run the portfolio locally on your machine:

### Option 1: Direct File Open
Simply double-click `index.html` or open it in any web browser.

### Option 2: Local HTTP Server (Python)
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Local HTTP Server (Node.js / npx)
```bash
npx serve .
```
